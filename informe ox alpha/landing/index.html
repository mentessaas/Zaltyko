Aislamiento total entre academias

411 políticas de seguridad a nivel de base de datos y una arquitectura donde el sistema deduce a qué academia pertenece cada petición desde la propia base de datos. Los datos de una academia jamás cruzan la frontera de otra.

Pagos verificados, no confiados

Stripe, Lemon Squeezy y Mailgun validan criptográficamente cada webhook. Si una firma no cuadra, la operación se rechaza. El dinero entra con el mismo rigor con el que se factura.

Calidad vigilada por máquinas

Desarrollamos puertas de control propias que analizan el código antes de cada despliegue: lecturas acotadas, autorización antes de validación, cero rutas huérfanas. Los errores mueren en desarrollo, no con clientes.

Y los tenemos citados, con fecha.

Una auditoría honesta encuentra cosas. El valor está en que cada hallazgo crítico tiene dueño, arreglo y plazo. Estos son los tres que se resuelven primero.

  1. Crítico

    Refuerzo de cabeceras de seguridad HTTP

    El navegador de nuestros usuarios merece protección explícita contra inyección y secuestro de sesión. El arreglo es quirúrgico: configuración, no reescritura. Plazo: esta semana.

  2. Crítico

    Verificación de tipos devuelta al pipeline

    Un script de pruebas rompió la verificación de tipos y el despliegue la tenía silenciada. Se corrige el script y la verificación vuelve a ser obligatoria: nada roto volverá a llegar a producción en silencio. Plazo: esta semana.

  3. Crítico

    Dependencia de hojas de cálculo traída a registro oficial

    Una librería de Excel se instalaba desde un servidor externo en lugar del registro público de paquetes. Se sustituye por su equivalente auditado. Plazo: esta semana.

Los 8 hallazgos de severidad media (duplicación interna de código de autorización, límites de peticiones no atómicos, rutas fuera de convención) están documentados con evidencia y asignados al plan. Ninguno afecta datos de clientes hoy.

Hoja de ruta: de sólido
a imparable.

Trece acciones priorizadas por impacto sobre esfuerzo. El plan completo vive en la vault operativa; esta es la lectura ejecutiva.

  1. Ahora

    Blindaje

    Cabeceras de seguridad, typecheck obligatorio en el pipeline y dependencias en registro oficial. Tres arreglos, un objetivo: que la plataforma sea invulnerable por diseño.

  2. Este mes

    Consolidación

    Unificación del sistema de autorización, límites de peticiones atómicos y el 100% de las rutas bajo convención única. Menos superficie donde pueda esconderse un error.

  3. Este trimestre

    Escalado

    Consolidación de la capa pública, cobertura de tests con mínimos exigibles en CI, caché selectiva para el directorio público y adelgazamiento del bundle. Preparado para 10× academias sin reescribir nada.

  4. Continuo

    Producto

    Notificaciones a familias, gestión completa de métodos de pago y modernización del tooling. La deuda que queda es de producto, no de cimientos.
